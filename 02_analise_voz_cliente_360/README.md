# Análise Voz do Cliente 360º

## Objetivo

Consolidar múltiplos canais de feedback do cliente em uma visão analítica única, permitindo monitorar satisfação, reputação e principais pontos de melhoria.

## Fontes de Dados

- NPS
- Google Reviews
- CSAT
- Reclame Aqui

## Tecnologias Utilizadas

- Oracle Database
- SQL (CTEs e Joins)
- API REST / JSON
- Sensidia
- Power BI
- Power Query
- Excel / SharePoint Online
- RPA

## Arquitetura da Solução

Cada fonte de dados possui um fluxo específico de captura e integração, convergindo para o banco Oracle e posteriormente para dashboards no Power BI.

## Principais Indicadores

- NPS
- CSAT
- Nota média Google
- Volume de reclamações
- Principais palavras citadas
- Principais áreas detratoras
- Segmentação por convênio
- Segmentação por campanha
- Paciente de 1ª vez vs recorrente

## Resultados Gerados

- Visão consolidada da experiência do cliente.
- Identificação de causas-raiz de insatisfação.
- Apoio à priorização de melhorias.
- Monitoramento da reputação institucional.
